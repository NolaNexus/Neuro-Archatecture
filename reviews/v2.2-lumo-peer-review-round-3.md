## 1. Verdict

The paper cannot exit green through another prose pass. It exits by running Epoch 0 and the falsification trials. Another revision that only rewrites sentences will reproduce the failure this round found.

**Central diagnosis — disposition by relabeling.** The revision log claims every prior finding was "adopted." The text shows three renamed-and-left-standing cases:

- **M1** became "a number is a computation" while the number is an embedding of prose.

## 2. Blocking findings

### R1 [BLOCKING] The both-direction falsifier is still one-directional

**Finding.** The Abstract and §5 claim falsifiability in both directions. §5.2 says "falsifiable downward" and supplies only a downward test — after opening with "A count armed in only one direction is not falsifiable." The paper criticizes its own defect in the sentence that commits it.

**Fix.** Add the upward falsifier: a residual error class no stage can represent, *plus* an ablation showing a fifth stage and its pair improve golden-set error at a better cost-quality point. Absent both clauses, the count is a design prior, and the Abstract must say so. v2.3 does this.

**Falsifier of the fix.** If no such residual class can be exhibited on the golden set after the census, the paper must state in the Abstract that the stage count is unfalsifiable upward and stop claiming otherwise.

### R2 [BLOCKING] The stage-merger falsifier does not test the stage count

**Finding.** Pair agreement measures witness independence. A stage can have perfectly decorrelated witnesses and still be unnecessary. Reading pair fusion as evidence against the stage count is a non sequitur, and 9.11 repeats it.

**Fix.** Split the tests. Pair fusion triggers decorrelation promotion and refutes the *two-witness* claim. Stage necessity is tested by ablation: bypass the stage's transformation, measure downstream quality and cost, and retire the stage if nothing degrades.

**Falsifier of the fix.** If the ablation cannot be run because the transformation cannot be bypassed without changing the task, the stage count is not testable on this substrate and must be marked so.

### R3 [BLOCKING] "A number is a computation" is vacuous

**Finding.** §6 and §8 restate Law 5 as "a number is a computation, not an interpretation." Sentiment scores, embeddings, and hashes are all numbers. The criterion cannot distinguish a semantic judgment from a mechanical predicate. `position_volatility` is a learned semantic judgment with a numeric output, and it sits in the jerk's binding path.

**Fix.** Restate the bright line by provenance. Binding predicates read only typed schema fields and mechanical oracles: hashes, counts, booleans, line numbers, exit codes, test and compiler output. Text-derived learned features are themselves logged claims, stamped with model and version, and advisory — they may order a queue, never bind a verdict.

**Falsifier of the fix.** Any predicate in the built organism whose binding input traces to a model output is a Law 5 violation, found by provenance audit of the claim schema.

### R4 [BLOCKING] The integrity poll sits inside the correlation structure it guards

**Finding.** §5.5 and 9.12 route the ground-truth channel through the Cartographer — a model reading the same artifacts, likely from the same backbone family as the witnesses it audits. A poll correlated with the pipeline cannot witness against it.

**Fix.** Anchor polls to mechanical oracles first: tests, type checkers, linters, schema validators, compiler output, git hashes and diffs, file existence. Use model re-perception only for the residue, stamped as a learned claim. Define independence operationally as alarm precision and recall against the golden set, and measure it.

**Falsifier of the fix.** A poll whose alarms do not separate true divergences from noise on the golden set is deleted under Law 4. That is the paper's own rule; it now has a statistic attached.

### R5 [BLOCKING] The golden set is a taxonomy, not a benchmark

**Finding.** §13 names nine lesion classes but gives no fixtures, item counts, expected outcomes, scoring rubric, held-out split, or power analysis. Every falsifier grades against "the golden set," so every falsifier is unpowered.

**Fix.** Publish at least twenty fixtures per class with expected outcomes and pass criteria; a rubric with inter-rater reliability; a held-out split; and a pre-registered power analysis that fixes X and N. Until then, mark the falsifiers unpowered rather than verdicted.

**Falsifier of the fix.** If inter-rater reliability on the rubric falls below the pre-registered floor, the golden set cannot grade anything and the falsification program stops until the rubric is repaired.

## 3. Major findings

### R6 [MAJOR] The serial pipeline is immunized by definition

§5.3 says "out-of-order consultation is noise by definition." Coding agents interleave perception and decision; the brain borrowed from is recurrent. Make the pipeline a default schedule with a measured exception class, and add a serial-versus-interleaved ablation. If interleaving wins on the golden set, the invariant is a preference, not a law.

### R7 [MAJOR] The pair-health statistic is confounded

Raw agreement conflates "both right" with "both wrong," and a pair can game the band by manufacturing disagreement. Measure error-conditional disagreement, P(disagree | at least one wrong), plus a shared-versus-independent error split and kappa on correctness. Import the ambiguity decomposition: ensemble error = average individual error − ambiguity. Run a diversity probe before funding a pair.

### R8 [MAJOR] The lane economy omits memory bandwidth and NUMA

"Residency is RAM, activation is threads" is wrong on this host. Decode is bandwidth-bound: roughly 60 GB/s per socket at DDR4-1866, about 120 GB/s aggregate, two NUMA nodes at distance 21. Separate prefill (compute-bound, attention-quadratic) from decode. Add GB/s as a third axis, pin lanes per node, and publish the lane × thread × bandwidth surface. The slogan becomes "bandwidth, not residency."

### R9 [MAJOR] The cerebellum mapping is the weakest unmarked metaphor

An embedding index and warm context are a retrieval cache, not a forward model. Give the organ its actual job: predict tool-call and diff outcomes, compare prediction to outcome, and publish prediction error as a calibration signal. That also supplies the missing action-to-perception recurrent channel.

### R10 [MAJOR] The "eight divisions" is a mixed-granularity partition

Brainstem levels, a nucleus inside the pons, a set of structures, and a whole forebrain are not one partition. The engineering partition is fine. The anatomical warrant is not, and §2 makes names load-bearing. Record the withdrawal in Appendix B or re-cut at one granularity.

### R11 [MAJOR] Law 4 conflicts with Appendix D

Law 4 forbids a resident model that is never routed to. D.4 justifies warm standby and diversity. Define warm standby as a declared funding class: full residency rent, a minimum routing frequency per epoch, and demotion to cold storage below the floor.

### R12 [MAJOR] Bandit credit assignment is underpowered

Epoch-level reward is delayed, low-dimensional, and confounded by task difficulty. Live exploration means choosing worse routes on real work. Log every route, evaluate off-policy (IPS/doubly robust), explore in shadow mode, carry a cost-aware prior, and add a forgetting/drift mechanism. The rule-based router is the control arm.

### R13 [MAJOR] Registry and machine diverge

The registry's leading heavyweight, `gpt-oss:120b`, is not installed on the host; several installed models are absent from the registry. Q1 and Q7–Q9 ask for answers "given Epoch 0 measurements" that do not exist. Freeze the registry at a measured snapshot, split verified-installed from watchlist, exclude the watchlist from the census matrix, and run Epoch 0 before asking.

## 4. Secondary observations

- **R14. Warrant strength is overstated.** Parietal "solidly grounded" overstates a task-dependent and debated lateralization; soften to "directionally supported." Frontal alpha-asymmetry has modest test-retest reliability, so "directionally robust" is too strong.
- **R15. The Chronicle is a transcript, not an episodic store.** Add pattern separation and completion, and measure interference rather than assuming the one-way flow solves it.
- **R16. The lateralization rule is ad hoc.** Occipital is exempt and temporal labels are "organizational." Either drop the rule or state it as a naming convention; the binding requirement is two witnesses per stage.
- **R17. RAPL scope and marginal joules.** Specify package versus DRAM domains, cross-check with a wall meter, and measure task energy net of idle, since idle power dominates sparse tasks.
- **R18. "Epoch" is overloaded.** It means development stage in §12 and training epoch in ML usage. Rename one sense.
- **R19. Appendix E overstates immutability.** "Sessions are not edited" is a convention, not a tamper hard-fail. The Ledger row should be Approximate and the tamper check must be built, not inherited.

- **BLUEPRINT — FOR BUILD** — all constants measured with uncertainty, all falsifiers verdicted, survivor set documented, and shorter than the Green Paper.

"GREEN PAPER — FOR CONSULTATION" is not a stable state.
