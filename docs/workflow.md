# Workflow

Part of the [repository guidelines](../AGENTS.md).

## Consultation Workflow

Copy **`Consultation Response Form (Edition 3).md`** into `peerReview/` and state the paper version in the header. Every response needs a definite **Position**, a **Mechanism** (*how*), and a **Falsifier** that could kill the proposal. No hedges; "no position" is stated explicitly.

## Revising the Paper

- Bump the `**Version:**` header (v2.2 → v2.3 …) and add an Appendix C row; no finding is silently dropped.
- Registry or lane-economy changes: update Appendix D and the affected §5.7 / Q8–Q9 text together.
- Substrate-mapping changes: update Appendix E and the affected Appendix B rows (B11–B16) together.
