# Project Structure

Part of the [repository guidelines](../AGENTS.md).

## Layout

```
paper/     the Green Paper, current and archived
forms/     consultation response forms
reviews/   completed peer reviews and audits
docs/      contributor and agent guides
```

## Files

- `paper/green-paper-v2.2.md` — the canonical paper (526 lines: 14 sections, Appendices A–E). "The green paper" always means this file; read it whole before editing. The version is in the header; the filename is renamed to match on each bump.
- `paper/archive/nola-green-paper-v1.2.md` — superseded edition; input only.
- `forms/consultation-response-form-edition-3.md` — current template. Copy it into `reviews/`; never edit it in place.
- `forms/consultation-response-form-edition-2.md` — historical.
- `reviews/` — completed reviews and audits from the two prior rounds.

`reviews/GreenPaperPeerAudit(lumo_max_.md` is missing its closing paren — a long-standing quirk; don't "fix" it without asking.

## Filenames Lie; Headers Don't

Trust `**Version:**`, not the filename:

| File | Actual version |
|---|---|
| `reviews/CompletedConsultationForm(apertus_1.5).md` | a v1.2 response, not v1.5 |

The canonical paper and its archived predecessor now carry honest names, so the table has one entry. A renamed or added file that contradicts its header belongs here.
